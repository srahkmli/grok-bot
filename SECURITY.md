# Security policy

This repository holds Firstmate's public instructions and templates. It does not run a service, and it does not store credentials.

## Reporting a vulnerability

Report a vulnerability privately through GitHub private vulnerability reporting.

1. Open the [Security tab for this repository](https://github.com/srahkmli/grok-bot/security).
2. Choose **Report a vulnerability**.

The private report form is [here](https://github.com/srahkmli/grok-bot/security/advisories/new). You need to be signed in to GitHub to submit it.

Do not open a public issue. Do not send email. This project has no security email address.

## Credentials

GitHub, Calendar, and Notion connections stay in the Grok Bot app. Do not put tokens, credentials, private document IDs, or customer data in an issue, a pull request, or a commit.

If a secret lands in the repository, send a private report as above. Then remove it in a pull request and rotate that credential where it was issued.
